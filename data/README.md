# Data

Datasets are **not** included in this repository (they are large and, in some
cases, redistribution is restricted). This directory is where the preprocessing
scripts write their output.

Download and preprocessing instructions will be documented here — see
`scripts/` for the preprocessing entry points.

Expected layout after preprocessing:

```
data/
├── qm9/          # QM9 molecules
├── trip/         # e-scooter trip point sets
└── earthquake/   # earthquake catalog
```
